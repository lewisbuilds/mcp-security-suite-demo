## GitHub Actions and release guidance

For existing or future pipeline work, read
`.github/instructions/actions-governance.instructions.md` before editing.
Use the relevant local skills in `.github/skills/`: `github-actions-efficiency`,
`github-actions-hardening`, `github-actions-runtime-upgrade-conventions`, and
`github-release`. Load references only as needed. Preserve project-specific rules,
required checks, supported runtimes and release authorization.
